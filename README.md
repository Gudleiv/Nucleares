# NUCLEARES — русская локализация руководства пользователя

Русская версия официального руководства к симулятору атомной электростанции
NUCLEARES: **`NUCLEARES - Руководство пользователя.pdf`**.

Оригинал — `NUCLEARES - User Manual.pdf` (161 страница A4, версия руководства 1.8).

## Что сделано

* Переведён весь текст руководства — 1226 абзацев, ~35 400 слов.
* Ключевые термины ядерной установки продублированы английским оригиналом в
  скобках: во всех заголовках разделов и при первом упоминании термина внутри
  раздела — «регулирующие стержни (control rods)», «компенсатор давления
  (pressurizer)».
* Терминология сверена с официальной локализацией игры (`EN.dat` / `RU.dat` /
  `PrincipalEN.xml` / `PrincipalRU.xml`), чтобы названия приборов, клапанов,
  насосов и надписей на панелях совпадали с тем, что игрок видит на экране.
* Форматирование сохранено: поля и ширина колонки, кегли, выключка по формату,
  полужирный и курсив, подчёркивания, цветные примечания (красные — «в игре
  это…», синие врезки «In summary» с линейками), заливка заголовков разделов,
  маркированные списки всех уровней, обтекание текстом плавающих иллюстраций.
* Изображения перенесены без изменений — они не переводились.
* Алфавитный указатель переведён, отсортирован по русскому алфавиту и
  пересчитан под новую нумерацию страниц; добавлены закладки PDF (166 шт.).
* Единицы и числа приведены к российским нормам: «15,0 МПа», «345 °C»,
  «100 %», дата «11.06.2025».

Русский текст длиннее английского, поэтому объём вырос со 161 до 180 страниц.
Разбиение на разделы сохранено: каждый раздел начинается с новой страницы, как
в оригинале.

## Как это собрано

Конвейер полностью воспроизводим:

```sh
python3 tools/extract.py "NUCLEARES - User Manual.pdf" work/model.json
python3 tools/flatten.py  work/model.json work/flow.json
python3 tools/index_data.py work/model.json work/index.json
python3 tools/glossary.py work/flow.json work/glossary.json
python3 tools/chunk.py    work/flow.json work/chunks
#   ... перевод чанков (work/chunks/chunk_NN.json -> chunk_NN.ru.json)
python3 tools/normalize.py work/chunks/*.ru.json work/headings.ru.json
python3 tools/merge.py    work/flow.json work/chunks work/flow.ru.json
python3 tools/build.py    work/flow.ru.json "NUCLEARES - Руководство пользователя.pdf" --field ru
python3 tools/qa.py       "NUCLEARES - Руководство пользователя.pdf"
```

| Файл | Назначение |
|---|---|
| `tools/extract.py` | PDF → постраничная модель: абзацы, раны со стилями, списки, плавающие иллюстрации, заливки и линейки |
| `tools/flatten.py` | постраничная модель → сквозной поток, склейка абзацев через границы страниц |
| `tools/index_data.py` | разбор алфавитного указателя оригинала |
| `tools/glossary.py` | глоссарий EN→RU из файлов локализации игры |
| `tools/chunk.py` | нарезка потока на переводческие чанки с маркерами ранов `{n\|…}` |
| `tools/merge.py` | сборка перевода обратно в поток с сохранением оформления |
| `tools/normalize.py` | приведение терминологии к игровой локализации |
| `tools/render.py` | вёрстка: колонка, выключка, списки, обтекание, колонтитулы |
| `tools/build.py` | сборка документа: обложка, дисклеймер, указатель, основная часть |
| `tools/qa.py` | проверка готового PDF |

Шрифт — PT Sans (кириллица, четыре начертания, `fonts/`); исходный шрифт
руководства — субсетированный CIDFont без кириллических глифов, поэтому текст
перенабран заново.

### Контроль точности

Тот же конвейер собирает английский текст обратно в PDF: получается 165 страниц
против исходных 161 (+2,5 %), то есть правила вёрстки воспроизведены верно и
рост объёма русской версии вызван самим переводом, а не пересборкой.
