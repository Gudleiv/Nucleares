# NUCLEARES — русская локализация руководства пользователя

**`NUCLEARES - Руководство пользователя.pdf`** — полный перевод официального
руководства к симулятору атомной электростанции NUCLEARES (оригинал:
`NUCLEARES - User Manual.pdf`, версия 1.8). Вёрстка, выделения и иллюстрации
оригинала сохранены, ключевые термины продублированы английским оригиналом в
скобках, а их перевод сверен с официальной локализацией игры (`RU.dat`,
`PrincipalRU.xml`), чтобы названия приборов и надписей на панелях совпадали с
тем, что игрок видит на экране.

Как собран документ и как его пересобрать — [`docs/PIPELINE.md`](docs/PIPELINE.md).
