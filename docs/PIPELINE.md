# Как собрано русское руководство

Русская версия получена не правкой исходного PDF, а пересборкой: из оригинала
извлекается структурная модель документа, текст переводится, после чего
документ верстается заново. Исходный шрифт руководства — субсетированный
CIDFont без кириллических глифов, поэтому текст перенабран заново шрифтом
PT Sans (`fonts/`, четыре начертания).

## Что сохранено

* Геометрия полосы набора, интерлиньяж, кегли, выключка по формату.
* Полужирный, курсив, подчёркивания, цветные примечания (красные «в игре
  это…», синие врезки «In summary» с линейками), заливка заголовков разделов.
* Маркированные списки всех уровней, обтекание текстом плавающих иллюстраций.
* Иллюстрации перенесены без изменений — они не переводились.
* Разбиение на разделы: каждый раздел начинается с новой страницы, как в
  оригинале.

Русский текст длиннее английского, поэтому объём вырос со 161 до 180 страниц.

## Терминология

Глоссарий EN→RU строится автоматически из файлов локализации игры
(`EN.dat` / `RU.dat` / `PrincipalEN.xml` / `PrincipalRU.xml`) по совпадающим
идентификаторам строк. Английский оригинал даётся в скобках во всех заголовках
разделов и при первом упоминании термина внутри раздела. `tools/normalize.py`
приводит терминологию к игровой во всех переведённых фрагментах, которые
переводились независимо друг от друга.

Алфавитный указатель переведён, отсортирован по русскому алфавиту и пересчитан
под новую нумерацию страниц; в PDF добавлены 166 закладок.

Единицы и числа приведены к российским нормам: «15,0 МПа», «345 °C», «100 %»,
дата «11.06.2025».

## Пересборка

```sh
python3 tools/extract.py "NUCLEARES - User Manual.pdf" work/model.json
python3 tools/flatten.py    work/model.json work/flow.json
python3 tools/index_data.py work/model.json work/index.json
python3 tools/glossary.py   work/flow.json work/glossary.json
python3 tools/chunk.py      work/flow.json work/chunks
#   ... перевод чанков (work/chunks/chunk_NN.json -> chunk_NN.ru.json)
python3 tools/normalize.py  work/chunks/*.ru.json work/headings.ru.json
python3 tools/merge.py      work/flow.json work/chunks work/flow.ru.json
python3 tools/build.py      work/flow.ru.json "NUCLEARES - Руководство пользователя.pdf" --field ru
python3 tools/qa.py         "NUCLEARES - Руководство пользователя.pdf"
```

| Файл | Назначение |
|---|---|
| `tools/extract.py` | PDF → постраничная модель: абзацы, раны со стилями, списки, плавающие иллюстрации, заливки и линейки |
| `tools/flatten.py` | постраничная модель → сквозной поток, склейка абзацев через границы страниц |
| `tools/index_data.py` | разбор алфавитного указателя оригинала |
| `tools/glossary.py` | глоссарий EN→RU из файлов локализации игры |
| `tools/chunk.py` | нарезка потока на переводческие чанки с маркерами ранов `{n\|…}` |
| `tools/merge.py` | сборка перевода обратно в поток с сохранением оформления |
| `tools/normalize.py` | приведение терминологии к игровой локализации |
| `tools/render.py` | вёрстка: колонка, выключка, списки, обтекание, колонтитулы |
| `tools/build.py` | сборка документа: обложка, дисклеймер, указатель, основная часть |
| `tools/qa.py` | проверка готового PDF |

Инструкция для переводчиков — `work/BRIEF.md`, готовый глоссарий —
`work/glossary.md`.

## Контроль точности

Тот же конвейер собирает обратно английский текст: получается 165 страниц
против исходных 161 (+2,5 %). То есть правила вёрстки воспроизведены верно, а
рост объёма русской версии вызван самим переводом, а не пересборкой.

`tools/qa.py` проверяет готовый файл на выход текста за пределы колонки,
отсутствующие глифы, непереведённые фрагменты и битые ссылки указателя.
