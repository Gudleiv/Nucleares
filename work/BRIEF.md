# Перевод руководства NUCLEARES на русский язык (регион: Россия)

Ты переводишь фрагмент официального руководства пользователя к симулятору
атомной электростанции NUCLEARES. Результат идёт в вёрстку PDF, поэтому формат
ответа обязателен к точному соблюдению.

## Формат данных

Входной файл — JSON-массив абзацев:

```json
{"id": 1031, "type": "heading", "section": "CONTROL PANEL: CORE",
 "s": "{0|Pressure Gauge:}{1|The pressure gauge provides a continuous readout...}"}
```

`s` — текст абзаца, разбитый на **раны** (участки с одинаковым оформлением).
`{0|...}` — ран №0, `{1|...}` — ран №1 и т. д. Ран 0 в маркированных пунктах, как
правило, — это выделенный полужирным термин-заголовок пункта.

**Правила по ранам:**

- Сохрани все маркеры `{n|...}` с теми же номерами. Ни один ран не удаляй и не
  добавляй новых номеров.
- Номера могут идти в другом порядке, если этого требует русский синтаксис.
- Переводи абзац целиком как связный текст, а потом распределяй по ранам так,
  чтобы каждый фрагмент оставался в ране с тем же смыслом и оформлением.
- Внутри `{n|...}` не должно быть символов `{` и `}`.
- Если ран содержит только знак препинания или пробел — оставь его как есть.
- Не добавляй пробелы в начале/конце рана: вёрстка склеивает раны через пробел.

## Выходной формат

JSON-массив тех же объектов с полем `id` и переведённым `s`. Ничего больше:

```json
[{"id": 1031, "s": "{0|Манометр давления (Pressure Gauge):}{1|Манометр показывает...}"}]
```

Записать результат в файл, который тебе укажут. Файл должен быть валидным JSON
в кодировке UTF-8.

## Правила перевода

1. **Терминология.** Пользуйся `work/glossary.json` — это официальная русская
   локализация игры (сопоставление по ID из `EN.dat`/`RU.dat`). Названия
   приборов, клапанов, насосов, режимов и надписей на панелях должны совпадать
   с игрой. Глоссарий составлен автоматически, поэтому проверяй по контексту:
   короткие слова могли попасть туда из несвязанного места.
2. **Заголовки разделов** уже переведены в `work/headings.ru.json` — сверяйся с
   ними, чтобы терминология внутри раздела совпадала с его заголовком. Если
   абзац из твоего чанка есть в этом файле, используй готовый перевод дословно.
3. **Дублирование английского в скобках.** Английский оригинал в скобках даётся:
   - в заголовках (это уже сделано в `headings.ru.json`);
   - при **первом упоминании** ключевого термина ядерной установки внутри
     раздела (`section`) — систем, контуров, узлов, приборов, режимов, органов
     управления: «управляющие стержни (control rods)», «компенсатор давления
     (pressurizer)», «активная зона (core)».
   Дальше по тексту раздела — только по-русски. Не дублируй общие слова
   («вода», «температура», «оператор») и не дублируй термин повторно.
4. **Надписи на панелях и клавиши** — как в игре: если элемент интерфейса
   подписан по-английски (`All Set`, `SCRAM`, `Open / Close / Secure`, `[F]`,
   `[TAB]`), сохрани английское написание, при первом упоминании дай перевод в
   скобках. Клавиши в квадратных скобках не переводятся.
5. **Числа и единицы.** Значения не меняй. Десятичный разделитель — запятая
   («15,0 МПа»), разряды тысяч — неразрывный пробел («2 250 psi» → «2250 psi»
   можно оставить слитно, если так короче). Единицы переводи: bar → бар,
   MPa → МПа, atm → атм, psi → psi, K → К, °C → °C, °F → °F, rpm → об/мин,
   MW → МВт, kW → кВт, V → В, Hz → Гц. Проценты — «100 %» с пробелом.
6. **Стиль.** Технический, нейтральный, безличный — как в отраслевой
   документации: «оператор устанавливает», «клапан открывается», а не «вы
   должны». Обращение к игроку — на «вы» со строчной буквы, если оно есть в
   оригинале. Не сокращай и не расширяй содержание: один абзац оригинала — один
   абзац перевода.
7. **Кавычки** — «ёлочки», внутренние — „лапки“. Тире — длинное (—), дефис в
   словах — обычный.
8. **Буква ё** — пишется.
9. Названия `NUCLEARES`, `AERILIAN GAMES` не переводятся и не склоняются.

## Чего делать нельзя

- Менять номера или количество маркеров `{n|...}`.
- Переводить содержимое изображений (их в тексте нет).
- Добавлять примечания переводчика, комментарии, markdown-разметку.
- Оставлять непереведённые английские предложения (кроме надписей интерфейса).
